# AI Travel Planner

An AI-powered travel planning web application built using Flask, Machine Learning, and Google Gemini AI.

## Features

- Personalized AI travel itinerary
- Expense prediction using Machine Learning
- Tourist place recommendations
- Hotel recommendations
- PDF download of trip plan
- Responsive user interface

## Technologies Used

- Python
- Flask
- Google Gemini API
- Scikit-learn
- Pandas
- HTML
- CSS
- JavaScript
- ReportLab

## Future Enhancements

- Live Weather
- Google Maps Integration
- User Login
- Travel History
